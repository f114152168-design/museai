# Museai

AI-powered electronic music creation platform. Create music with natural language, arrange on a timeline, or live code in real time.

## Features

- **Chat Mode** - Describe music in natural language, AI generates audio
- **Timeline Mode** - DAW-like interface for arranging tracks
- **Live Coding Mode** - Algorithmic composition with real-time Web Audio playback

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Zustand (state management)
- Tone.js (audio synthesis)
- Monaco Editor (live coding)
- NextAuth.js (authentication)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start creating.
